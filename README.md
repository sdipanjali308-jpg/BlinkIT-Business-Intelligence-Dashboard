 📊 BlinkIT Business Intelligence Dashboard

A data-driven analysis of BlinkIT sales data to understand revenue trends, product category performance, outlet characteristics, customer ratings, and key business metrics for better decision-making.


📌 About the Project

This project is based on analyzing BlinkIT grocery data using Microsoft Power BI. We worked on this project to improve our practical data analytics skills and understand how raw data can be transformed into meaningful business insights.

The main focus was on preparing the data, organizing it, and using visualizations to present information in a clear and understandable way.

 🔄 Project Workflow

 1. 📂 Data Collection

For this project, we used a BlinkIT grocery dataset containing information related to grocery products, sales, outlets, and other business-related attributes.

The dataset was collected from an available source on Kaggle and used as the foundation for our analysis. It provided the information needed to explore grocery sales patterns and understand different aspects of the business.

After collecting the data, we moved on to data preprocessing and cleaning to prepare it for further analysis and visualization in Power BI.

 2. 🧹 Data Preprocessing

Before creating the dashboards, the data needed to be prepared properly. This stage involved:

- Understanding the dataset and its columns.
- Checking for missing or blank values.
- Identifying and handling duplicate records.
- Checking data types and correcting them where required.
- Cleaning and organizing the data for analysis.

 3. 🗂️ Data Modelling

- Organizing the data in Power BI.
- Creating relationships between tables, wherever required.
- Preparing the data model for analysis.

4. 📊 Data Visualization

- Creating interactive visualizations using Power BI.
- Presenting grocery-related information through charts and graphs.
- Making the dashboards easier to understand.

🛠️ Tools & Technologies

-  Microsoft Power BI – Dashboard creation and reporting.
-  Power Query – Data preparation and transformation.
-  DAX Queries – Calculations and analytical measures.
-  Data Cleaning – Preparing data for analysis.
-  Data Modelling – Organizing data for reporting.
-  Data Visualization – Presenting insights through charts and graphs.


📈 Report 1: Grocery Sales Overview

This dashboard focuses on the overall sales performance and key business indicators of BlinkIT.

1. Total Sales: The dashboard provides an overview of BlinkIT's sales performance, including total sales of 472.13K and average sales of 140.94.

2. Item Performance:A total of 3,350 items are sold, with an average customer rating of 3.92.

3. Outlet Establishment: The Outlet Establishment chart shows that sales increased significantly from 2010 to 2015 and remained stable afterward.

4. Fat Content Analysis: Regular Fat products contribute more sales (2.17K) than Low Fat products (1.18K).

5. Outlet Size Analysis: Medium-sized outlets have the highest contribution, followed by Small and High-sized outlets.

6. Item Type Analysis: Fruits and Vegetables (71K) and Snack Foods (69K) are the top-selling categories.

Key Insight: Overall, this dashboard helps identify top-performing product categories, outlet characteristics, and important sales trends to support better business decisions.

 🏪 Report 2: Store Performance Analysis

This dashboard provides a deeper understanding of BlinkIT's store performance, product categories, and outlet characteristics.

1. Overall Performance: The dashboard highlights 1.20M total sales, 16 item categories, and an average customer rating of 3.92.

2. Item Type Analysis:Fruits and Vegetables, Snack Foods, and Household products are among the top-selling categories.

3. Outlet Type Analysis: Supermarket Type 1 is the leading outlet, with approximately 5.6K items sold.

4. Outlet Size Analysis: Medium-sized outlets generate the highest sales (0.51M), followed by Small (0.44M) and High-sized outlets (0.25M).

5. Outlet Establishment Trends: The Outlet Establishment Year chart helps compare outlet growth and establishment trends across Tier 1, Tier 2, and Tier 3 locations.

6. Average Item Weight: The Item Weight analysis shows that Others, Starchy Foods, and Dairy have the highest average item weights.

Key Insight: Overall, this dashboard helps understand sales distribution, customer ratings, product performance, and outlet efficiency for better business decision-making.
