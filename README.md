BlinkIT Business Intelligence Dashboard📊

A data-driven analysis of Blinkit sales data to understand revenue trends, product category performance, outlet characteristics, customer ratings, and key business metrics for better decision-making.


About the Project

This project is based on analyzing BlinkIT grocery data using Microsoft Power BI. We  worked on this project to improve our practical data analytics skills and understand how raw data can be converted into meaningful business insights.
The main focus was on preparing the data, organizing it, and using visualizations to make the information easier to understand.

 Project Workflow:

1.Data Collection

For this project, We used a BlinkIT grocery dataset containing information related to grocery products, sales, outlets, and other business-related attributes.

The dataset was collected from an available dataset source from Kaggle and used as the foundation for the analysis. It provided the information needed to explore grocery sales patterns and understand different aspects of the business.

After collecting the data, We moved on to data preprocessing and cleaning to prepare it for further analysis and visualization in Power BI.

2. Data Preprocessing
Before creating the dashboard, the data needs to be prepared properly. This stage involves:
- Understanding the dataset and its columns.
- Checking for missing or blank values.
- Identifying and handling duplicate records.
- Checking data types and correcting them where required.
- Cleaning and organizing the data for analysis.

3. Data Modelling
- Organizing the data in Power BI.
- Creating relationships between tables, wherever required.
- Preparing the data model for analysis.

4. Data Visualization
- Creating interactive visualizations using Power BI.
- Presenting grocery-related information through charts and graphs.
- Making the dashboard easier to understand.

 Report 1 Description:

1.This dashboard provides an overview of Blinkit's sales performance, including total sales of 472.13K and average sales of 140.94.
2.A total of 3,350 items are sold, with an average customer rating of 3.92.
3.The Outlet Establishment chart shows that sales increased significantly from 2010 to 2015 and remained stable afterward.
4.The Fat Content analysis shows that Regular Fat products contribute more sales (2.17K) than Low Fat products (1.18K).
5.The Outlet Size analysis indicates that Medium-sized outlets have the highest contribution, followed by Small and High-sized outlets.
6.The Item Type analysis shows that Fruits and Vegetables (71K) and Snack Foods (69K) are the top-selling categories.
Overall, the dashboard helps identify top-performing product categories, outlet characteristics, and important sales trends to support better business decisions.

Report 2 Description:

1. This dashboard provides insights into Blinkit's store performance, including 1.20M total sales, 16 item categories, and an average customer rating of 3.92.
2. The Item Type analysis shows that Fruits and Vegetables, Snack Foods, and Household products are among the top-selling categories.
3. The Outlet Type analysis highlights Supermarket Type 1 as the leading outlet, with approximately 5.6K items sold.
4. The Outlet Size analysis shows that Medium-sized outlets generate the highest sales (0.51M), followed by Small (0.44M) and High (0.25M).
5. The Outlet Establishment Year chart helps compare outlet growth and establishment trends across Tier 1, Tier 2, and Tier 3 locations.
6. The Item Weight analysis shows that Others, Starchy Foods, and Dairy have the highest average item weights.
7. Overall, this dashboard helps understand sales distribution, customer ratings, product performance, and outlet efficiency for better business decision-making.
